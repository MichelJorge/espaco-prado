Espaço Prado — Clínica de Psicopedagogia
Website institucional desenvolvido para o Espaço Prado, especializado em atendimento psicopedagógico, suporte a pais e responsáveis, e gestão voltada para a aprendizagem e desenvolvimento infantil.

Sobre o Projeto
O site foi desenvolvido com foco na experiência do usuário, oferecendo uma navegação leve, acolhedora e fluida. Sua arquitetura visual utiliza tons pastéis elegantes e tipografia clara para transmitir calma, profissionalismo e confiança.

Destaques da Aplicação
Design Acolhedor: Visual minimalista em tons de lavanda, bege suave e cinza neutro.

100% Responsivo: Adaptável a computadores, tablets e dispositivos móveis.

Animações Fluidas: Efeitos suaves ao rolar a página via IntersectionObserver.

Sem Frameworks: Feito em código nativo, garantindo máxima velocidade de carregamento.

Tecnologias Utilizadas

HTML5: Estrutura semântica e acessível.

CSS3: Variáveis globais, Flexbox, CSS Grid e animações leves.

JavaScript (ES6+): Controle do menu mobile e scroll suave.
